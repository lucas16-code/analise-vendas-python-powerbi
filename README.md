# Análise de Vendas com Python e Power BI

## Sobre o projeto

Projeto de análise de dados comerciais desenvolvido com o objetivo de organizar, tratar e visualizar informações de vendas, auxiliando na identificação de padrões e no acompanhamento do desempenho comercial.

## Tecnologias utilizadas

- Python
- Pandas
- Microsoft Power BI
- Excel
- Git e GitHub

## Estrutura do projeto

- `scripts/` — scripts Python utilizados no tratamento dos dados.
- `dados_originais/` — arquivos originais utilizados na análise.
- `dados_tratados/` — arquivos gerados após o tratamento dos dados.

**Observação:** os arquivos de dados comerciais não são disponibilizados publicamente por questões de confidencialidade.

## Etapas do projeto

1. Organização dos arquivos de vendas.
2. Tratamento e preparação dos dados com Python.
3. Estruturação dos dados para análise.
4. Desenvolvimento de indicadores e visualizações no Power BI.

## Objetivo

Demonstrar a aplicação de técnicas de análise de dados e Business Intelligence para apoiar a tomada de decisões comerciais.
